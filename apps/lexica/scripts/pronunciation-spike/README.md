# Pronunciation spike (Đợt 6)

Scripts behind `docs/LEXICA_PRONUNCIATION_SPIKE.md`: score on-device phone models on speechocean762 (`evalmdd.py`), export them to int8 ONNX (`export.py`), and time them in Chromium (`serve.mjs`, `bench.mjs`, `bench.html`). Not part of the app or CI; see the doc for how to run them.
