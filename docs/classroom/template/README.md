# Khung mô-đun lớp học

Chép rồi đổi `myapp` / `MyApp` thành id và tên app của bạn (xem `docs/CLASSROOM.md`).

| Mẫu | Chép tới |
|---|---|
| `sql/classroom_myapp.sql` | `packages/classroom-myapp/sql/classroom_myapp.sql` |
| `package/` | `packages/classroom-myapp/` |
| `teach/index.tsx` | `apps/teach/app/modules/myapp/index.tsx` |

Ví dụ trong mẫu: một app luyện nói, giáo viên giao một chủ đề, học viên báo số buổi và số phút đã nói.
Thay bằng thiết kế thật của app bạn.
